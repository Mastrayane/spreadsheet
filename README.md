# Formula Spreadsheet Engine

## 1. Описание
**Formula Spreadsheet Engine** — движок электронной таблицы с поддержкой формул, включая: 
- Арифметические операции (`+, -, *, /`)
- Ссылки на ячейки (A1, XFD16384)
- Обработку циклических зависимостей
- Динамическое обновление зависимых значений
- Расширенную обработку ошибок (#REF!, #VALUE!, #ARITHM!)

**Стек технологий**: 
- Язык: C++17
- Парсинг формул: ANTLR4 (Runtime + Codegen)
- Сборка: CMake 3.8+
- Тестирование: Custom Test Framework

**Цель проекта**: Демонстрация реализации:
- Парсинга DSL (языка формул) с помощью ANTLR
- Реактивной модели вычислений с инвалидацией кэша
- Обработки графов зависимостей между ячейками

---

## 2. Системные требования и запуск

### Требования:
- Компилятор C++ с поддержкой C++17 (GCC 10+, Clang 12+, MSVC 2019+)
- CMake ≥ 3.8
- Java 11+ (для генерации парсера ANTLR)
- 500 МБ свободного места (для зависимостей ANTLR)

### Инструкция:
```bash
# 1. Клонировать с зависимостями
git clone --recursive https://github.com/your-repo/spreadsheet-engine.git

# 2. Сборка
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
cmake --build . --config Release

# 3. Запуск тестов
./src/spreadsheet
