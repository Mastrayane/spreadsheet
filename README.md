# Электронная таблица (Spreadsheet)
**Проект представляет собой реализацию электронной таблицы с поддержкой формул, ссылок на ячейки и базовых арифметических операций. Основная цель проекта — создание легковесного и расширяемого движка для работы с табличными данными, который может быть интегрирован в более крупные приложения.**

### Функциональность:
- Поддержка текстовых и числовых значений в ячейках.
- Возможность задавать формулы с использованием арифметических операций (```+```, ```-```, ```*```, ```/```).
- Обработка ссылок на другие ячейки (например, ```=A1+B2```).
- Автоматическое обновление зависимых ячеек при изменении данных.
- Обнаружение и предотвращение циклических зависимостей.
- Валидация синтаксиса формул.
- Поддержка ошибок в формулах (например, деление на ноль, неверные ссылки).
- Печать таблицы в текстовом формате.
  
### Стек технологий:
- **Язык программирования:** *C++ (стандарт C++17)*
- **Парсер формул:** *ANTLR 4.13.2*
- **Система сборки:** *CMake*
- **Тестирование:** *Кастомный тестовый фреймворк (на основе макросов* ```ASSERT```*,* ```RUN_TEST```*)*

## Инструкция по развёртыванию
### Системные требования:
- *Компилятор C++ с поддержкой стандарта C++17 (например, GCC 9+, Clang 10+, MSVC 2019+)*
- *Утилита CMake (версия 3.8+)*
- *Java Runtime Environment (JRE) для работы с ANTLR*
- *ANTLR 4.13.2 (уже включён в проект)*

### Шаги для запуска:
1. Убедитесь, что у вас установлены все необходимые зависимости (CMake, компилятор C++, Java).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Mastrayane/spreadsheet.git
   cd spreadsheet
   ```
3.Соберите проект с помощью CMake:
```bash
mkdir build
cd build
cmake ../spreadsheet
cmake --build .
```
